[N.04/11]> How it works

News in. Precedents out.
The desk decides.

Request access
// 001

A filing, a wire story, a broker note, a line pasted from the desk chat. Any source. The resolver names the company and the event class.

A news item comes in

// 002

Same company first, then the same event class across the sector, matched on the text itself, inside the lookback you choose. Each precedent carries its measured reaction, cap band and regime.

Agents find precedents

// 003

Median, IQR, hit rate stated both ways, n. The cases that went the other way stay on the list. The analyst reads it, draws the conclusion and seals it with the evidence attached.

The analyst concludes

// 004

The window closes. The market answers. Sitrep scores the thesis per axis against dated thresholds and files the result next to the sealed evidence. The record is the rationale.

// 14 tools: precedents, base_rates, thesis, watch, memo, vault ...
// Every number the model quotes carries the panel and the document it came from.
from sitrep import Desk

desk = Desk(api_key=os.environ["SITREP_API_KEY"])

# One news item in, the precedents out
result = await desk.precedents(
    text="Tata Motors: JLR wholesale volumes down 11% YoY",
    lookback_years=5,
    n=20,
)

for case in result.cases:
    print(case.date, case.headline, case.abnormal_5d, case.vs_implied)

# Summary across the list: median, IQR, hit rate both ways, n
print(result.summary.median_5d, result.summary.hit_rate, result.summary.n)
# Every panel as JSON, with provenance on every number
curl -s https://api.sitrep.so/v1/precedents \
  -H "Authorization: Bearer $SITREP_API_KEY" \
  -d '{
    "text": "RBI holds repo at 6.5%, stance unchanged",
    "subject": "NIFTY",
    "lookback_years": 8
  }'

[N.07/11]> Invariants

Seven invariants.
None of them move.

Two clocks
@event_time · @ingestion_time

Sitrep stores when it happened and when we learned it in separate columns. A precedent is only what the desk could have known that morning.

Invariant 01 · enforced in code
Read more
@point_in_time
Point-in-time membership
Index and sector membership as they stood that day. Snapshotted by us. No survivorship.
Verified at the door
@ingestion

Ingestion sets the verification status, not the reader. An unverified item stays marked unverified on every panel it appears on.

Invariant 03 · enforced in code
Read more
Numbers from the data
@measurement_layer

Every number on a panel comes from the measurement layer and never from a model. CI fails the build if a model output reaches a number field.

Invariant 06 · CI-enforced
Read more
@per_axis
Grades stored per axis
One grade per axis, against a dated threshold. Re-read it years later and it means the same thing.
No order capability
@anywhere

Nothing in the system can place, route or size an order. There is no target price and no drafted view. The precedent list is the record.

Invariant 05 · by design
Read more
The analyst concludes
@the_desk

Sitrep retrieves and measures. The reading, the call and the responsibility stay with the person whose name is on the note.
